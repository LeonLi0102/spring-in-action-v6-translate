# 前言

Spring 于 18 多年前进入开发世界，其根本使命是使 Java 应用程序开发变得更容易。最初，这意味着为 EJB 2.x 提供一个轻量级的替代方案。但 Spring 才刚刚开始。多年来，Spring 扩展了其简单性的使命，以解决常见的开发挑战，包括持久化、安全性、集成、云计算等。

尽管 Spring 已经走过了近二十年的企业 Java 开发之路，但它并没有放缓的迹象。Spring 继续解决 Java 开发挑战，无论是创建部署到传统应用服务器的应用程序，还是部署到 Kubernetes 集群中的容器化应用程序。随着 Spring Boot 提供自动配置、构建依赖帮助和运行时监控，现在是成为 Spring 开发人员的最佳时机！

《Spring 实战》第六版是您学习 Spring 和 Spring Boot 的指南，已更新以反映两者提供的最佳功能。即使您是 Spring 新手，您也可以在第一章结束之前启动并运行您的第一个 Spring 应用程序。随着本书的深入，您将学习如何创建 Web 应用程序、处理数据、保护应用程序以及管理应用程序配置。接下来，您将探索将 Spring 应用程序与其他应用程序集成的选项，以及如何在 Spring 应用程序中利用响应式编程，包括新的 RSocket 通信协议。随着本书的结束，您将看到如何为生产环境准备应用程序，并了解部署选项。

无论您是 Spring 新手还是拥有多年 Spring 开发经验，这都是您旅程中的下一步。我为您感到高兴，并很高兴将此指南带给您。我期待看到您用 Spring 创建的内容！

—Craig Walls
