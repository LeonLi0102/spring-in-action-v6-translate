# 第四部分 部署 Spring

在第四部分中，您将为生产环境准备应用程序并了解如何部署它。

第 15 章介绍了 Spring Boot Actuator，这是 Spring Boot 的一个扩展，它将正在运行的 Spring 应用程序的内部结构公开为 REST 端点和 JMX MBean。

在第 16 章中，您将看到如何使用 Spring Boot Admin 在 Actuator 之上放置一个用户友好的基于浏览器的管理应用程序。您还将看到如何向 Admin Server 注册客户端应用程序以及如何保护 Admin Server 的安全。

第 17 章讨论如何将 Spring Bean 公开为 JMX MBean 以及如何消费它们。

最后，在第 18 章中，您将看到如何在各种生产环境中部署您的 Spring 应用程序，包括可以在 Kubernetes 中运行的容器化 Spring 应用程序。
