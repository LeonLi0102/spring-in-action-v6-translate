# 关于本书

《Spring 实战》第六版旨在帮助您使用 Spring Framework、Spring Boot 和 Spring 生态系统的各种辅助成员构建出色的应用程序。它首先向您展示如何使用 Spring 和 Spring Boot 开发基于 Web 的、由数据库支持的 Java 应用程序。然后通过展示如何使用响应式类型与其他应用程序和程序集成来扩展基础知识。最后，讨论如何为部署准备应用程序。

尽管 Spring 生态系统中的所有项目都提供了出色的文档，但本书做到了参考文档做不到的事情：提供一个动手实践的、项目驱动的指南，将 Spring 的元素组合在一起构建真实的应用程序。

**谁应该阅读本书**

《Spring 实战》第六版适用于想要开始使用 Spring Boot 和 Spring Framework 的 Java 开发人员，以及想要超越基础知识并学习 Spring 最新功能的经验丰富的 Spring 开发人员。

**本书的组织方式：路线图**

本书分为四个部分，共 18 章。第一部分涵盖构建 Spring 应用程序的基础主题：

* 第 1 章介绍 Spring 和 Spring Boot 以及如何初始化 Spring 项目。在本章中，您将迈出构建 Spring 应用程序的第一步，并在本书的整个过程中进行扩展。
* 第 2 章讨论使用 Spring MVC 构建应用程序的 Web 层。在本章中，您将构建处理 Web 请求的控制器和在 Web 浏览器中呈现信息的视图。
* 第 3 章介绍使用 JDBC 和 Spring Data JPA 持久化数据。
* 第 4 章介绍使用 Spring Security 保护应用程序。
* 第 5 章介绍如何使用配置属性来配置 Spring。

第二部分涵盖构建 Spring 应用程序的更多主题：

* 第 6 章介绍如何创建 RESTful 服务。
* 第 7 章介绍如何使用 Spring Cloud Gateway 构建 API 网关。
* 第 8 章介绍如何使用 Spring 发送和接收消息。
* 第 9 章介绍如何处理 NoSQL 数据库。
* 第 10 章介绍响应式 Spring。

第三部分涵盖 Spring 在生产中的使用：

* 第 11 章介绍测试。
* 第 12 章介绍部署 Spring 应用程序。

第四部分是附录：

* 附录 A 介绍如何设置开发环境。
* 附录 B 介绍如何在 Kubernetes 上部署 Spring 应用程序。

**关于作者**

Craig Walls 是 Spring Framework 的核心开发人员，也是多本 Spring 书籍的作者，包括《Spring in Action》和《Spring in Action》第五版。他在 Pivotal 担任 Spring 核心团队的工程师，负责 Spring Security 项目。他还是 No Fluff Just Stuff 巡回演讲的常客。
