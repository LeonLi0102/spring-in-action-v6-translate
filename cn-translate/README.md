# Spring 实战 (第 6 版)

![](./assets/cover.png)

《Spring 实战（第 6 版）》完整中文翻译，基于 Manning 出版社正式版本。

## 📚 翻译完成

本项目已完成全部 **18 章 + 附录** 的翻译工作。

### 翻译范围

| 部分 | 章节 | 内容 |
|------|------|------|
| **Part 1: 基础 Spring** | 第 1-6 章 | Spring 入门、Web 开发、数据处理、安全、配置 |
| **Part 2: 集成 Spring** | 第 7-10 章 | REST 服务、安全 REST、异步消息、集成 |
| **Part 3: 响应式 Spring** | 第 11-14 章 | Reactor、响应式 API、响应式数据、RSocket |
| **Part 4: 部署 Spring** | 第 15-18 章 | Actuator、管理、JMX 监控、部署 |
| **附录** | 附录 A | 引导 Spring 应用程序 |
