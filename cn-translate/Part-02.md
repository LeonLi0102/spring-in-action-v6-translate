# 第二部分 集成 Spring

第二部分的章节涵盖了帮助您将 Spring 应用程序与其他应用程序集成的主题。

第 7 章扩展了第 2 章开始的 Spring MVC 讨论，介绍了如何在 Spring 中编写 REST API。我们将介绍如何在 Spring MVC 中定义 REST 端点、使用 Spring Data REST 自动生成基于存储库的 REST 端点以及如何消费 REST API。

第 8 章介绍如何使用 Spring Security 对 OAuth 2 的支持来保护 API 的安全，以及如何在可以访问 OAuth 2 保护的 API 的客户端代码中获取授权。

在第 9 章中，我们将介绍使用异步通信使 Spring 应用程序能够使用 Java 消息服务（JMS）、RabbitMQ 和 Kafka 发送和接收消息。

最后，第 10 章讨论使用 Spring Integration 项目进行声明式应用程序集成。我们将介绍实时处理数据、定义集成流以及与电子邮件和文件系统等外部系统集成。
