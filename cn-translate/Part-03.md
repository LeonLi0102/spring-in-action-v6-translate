# 第三部分 响应式 Spring

在第三部分中，我们将探索 Spring 中对响应式编程的支持。

第 11 章讨论了使用 Project Reactor 进行响应式编程的基础知识，Project Reactor 是支撑 Spring 响应式特性的响应式编程库。然后我们将介绍 Reactor 最有用的一些响应式操作。

在第 12 章中，我们将重新讨论 REST API 开发，介绍 Spring WebFlux，这是一个从 Spring MVC 中借鉴了很多内容的 Web 框架，同时为 Web 开发提供了一种新的响应式模型。

第 13 章介绍使用 Spring Data 编写响应式数据持久化，以读写 Cassandra 和 Mongo 数据库中的数据。

第 14 章通过介绍 RSocket 来结束第三部分，RSocket 是一种支持响应式替代 HTTP 的通信协议。
