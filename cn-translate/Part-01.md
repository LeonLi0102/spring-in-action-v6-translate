# 第一部分 基础 Spring

本书的第一部分将帮助您开始编写 Spring 应用程序，同时学习 Spring 的基础知识。

在第 1 章中，我将快速概述 Spring 和 Spring Boot 的基础知识，并向您展示如何在构建 Taco Cloud（您的第一个 Spring 应用程序）时初始化 Spring 项目。在第 2 章中，您将深入了解 Spring MVC，学习如何在浏览器中呈现模型数据以及如何处理和验证表单输入。您还将获得一些关于选择视图模板库的建议。

在第 3 章中，您将为 Taco Cloud 应用程序添加数据持久化，我们将介绍如何使用 Spring 的 JDBC 模板以及如何使用预处理语句和键持有者插入数据。然后，您将看到如何使用 Spring Data 声明 JDBC（Java 数据库连接）和 JPA（Java 持久化 API）存储库。

第 4 章通过介绍另外两个用于将数据持久化到 Cassandra 和 MongoDB 的 Spring Data 模块，继续讲述 Spring 持久化的故事。第 5 章介绍 Spring 应用程序的安全性，包括自动配置 Spring Security、定义自定义用户存储、自定义登录页面以及防范跨站请求伪造攻击。

作为第一部分的结束，我们将在第 6 章中讨论配置属性。您将学习如何微调自动配置的 Bean、将配置属性应用于应用程序组件以及使用 Spring Profile。
